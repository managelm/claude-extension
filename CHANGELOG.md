# Changelog

All notable changes to the ManageLM Claude plugin will be documented in this file.

## [1.0.0] - 2026-11-17

First release of the ManageLM plugin for Claude.

- Works in claude.ai, Cowork and Claude Code, and connects to ManageLM over MCP with OAuth sign-in.
- `manage-servers` skill: Claude follows ManageLM's working rules (find the server first, prefer fleet searches, confirm risky changes, review before reverting).
- `setup` and `troubleshoot` skills for signing in, self-hosted portals and common problems.
